# Ollama + duckduckgo Search Integration

Tested example :  
[GitHub](https://github.com/alby13/ollama-internet-search-tool/blob/main/ddgsearch.py)

Pre-requesite :  
- **Ollama + gemma3** up and running 
- python   

```bash
python -m venv venv 
source ./venv/bin/activate

# pip install duckduckgo-search is deprecated  

pip install ollama ddgs

python main.py
```
